# 定時關機程式 (Scheduled Shutdown)

一個簡單、現代化的 Windows 定時關機工具。
提供直覺的圖形化介面，讓您輕鬆設定電腦自動關機的時間。

## ✨ 功能特色

*   **彈性時間輸入**：支援小數輸入（例如輸入 `1.5` 代表 1 小時 30 分鐘）。
*   **快速設定**：內建 2、4、6、8 小時快速按鈕，一鍵排程。
*   **即時狀態回饋**：清楚顯示預計關機的具體時間點。
*   **現代化介面**：清爽、易讀的操作視窗。
*   **安全防呆**：防止輸入無效格式，並可隨時取消排程。

## 📝 使用說明

1.  **自訂時間**：在輸入框輸入小時數（例如 `0.5` 為 30 分鐘），點擊「建立定時關機」。
2.  **快速按鈕**：直接點擊下方的小時按鈕即可。
3.  **取消**：點擊紅色的「取消關機」按鈕即可停止倒數。

## ⚠️ 注意事項

*   本程式專為 **Windows** 作業系統設計。
*   執行關機指令後，系統可能會跳出 Windows 原生的關機提示視窗，這是正常現象。
